# Roadmap

## Phase 0 — Foundation (current)

- New repository and operating charter.
- Source and domain registries.
- Versioned data model with a transparent bootstrap state.
- Visual command center.
- Daily heartbeat workflow.
- GitHub Pages deployment workflow.

## Phase 1 — First live surfaces

- Add a safe GitHub inventory adapter.
- Add local workspace inventory that reports without modifying existing projects.
- Add mission-scoped public-web research capture.
- Record source health and freshness in the dashboard.

## Phase 2 — Intelligence loop

- Add authenticated AI source adapters as accounts become available.
- Preserve raw prompts and responses.
- Add schema-validated synthesis items and comparison states.
- Add stable signal IDs and append-only lifecycle events.

## Phase 3 — Connection engine

- Extract entities and relationships from evidence.
- Require a mechanism and basis for every non-trivial edge.
- Surface cross-domain bridges, contradictions, and silent areas.

## Phase 4 — Action engine

- Turn high-value findings into missions.
- Track dependencies and expected value.
- Execute builds, repairs, and research tasks through safe computer workflows.
- Verify outcomes and write post-mortems.

## Phase 5 — Evergreen operations

- Add source-specific schedules and freshness SLAs.
- Detect stale prompts, stale signals, and stale dashboard views.
- Measure which sources and convergence modes actually predict useful outcomes.
- Keep the system current through repeat cycles rather than one-time setup.
